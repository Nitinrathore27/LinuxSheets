# LinuxSheets

I will be pushing my daily learning on Linux here.

## Contents

### 📁 `shell/`
Scripts created while learning shell variables and scripting in Linux:
- [`variables.sh`](./shell/variables.sh) - Demonstrates variable creation, special referencing rules, escaping, whitespace preservation, and command substitution.
- [`arithmetic.sh`](./shell/arithmetic.sh) - Demonstrates arithmetic expressions, addition, subtraction, multiplication, division, modulus, increments, and decrements using `$((expression))`.
- [`environment.sh`](./shell/environment.sh) - Explores standard environment variables, custom variable exports (`export`), child process scopes, and unsetting variables (`unset`).
